## Neovim Setup

Simple yet powerful neovim configuration with the following features:

1. Treesitter
2. Lsp servers
3. Completions blink.nvim
4. Formatting conform.nvim
5. Picker Snacks-picker
6. Explorer Snacks-explorer
7. Statusline mini.Statusline
8. Autopairs mini-autopairs
9. Indent guides Snacks-indent
10. Snacks Keys
